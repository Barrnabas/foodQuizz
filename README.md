# Food Nutrition Quiz

A fun, interactive web game that tests your knowledge about the nutritional values of various foods! Built with TypeScript, HTML5, and CSS3 Glassmorphism.

## Features
- **Dynamic Questions:** Questions are generated dynamically from an external JSON API.
- **Visual Feedback:** Instant red/green color feedback when you guess an answer.
- **Hint System:** Stuck? Use the hint button to reveal another random nutrient about the correct food!
- **Score Tracking:** Tracks your score over a 10-question round.
- **Modern UI:** Built using a sleek Dark Mode Glassmorphism aesthetic.

## Technologies Used
- HTML5
- CSS3 (Glassmorphism & Flexbox)
- TypeScript (Strict Mode)
- Google Fonts (Poppins)

## How to Run Locally 
1. Clone this repository to your local machine.
2. Install the TypeScript compiler if you haven't already: `npm install -g typescript`
3. Run the TypeScript compiler in watch mode: `tsc -w`
4. Use a local development server like **Live Server** (VSCode extension) to serve the HTML files.
5. Open `index.html` in your browser!

## API Data
The game fetches food nutrition data dynamically from a cloud-hosted JSON file. The data contains macronutrients, vitamins, and minerals for various ingredients.
